# Memetic Trojans

Code and data for *Memetic Trojans: Social Contagions as Carriers of Adversarial
Payloads in Agent Networks*.

A **memetic trojan** is a network-mediated attack in which an adversarial payload
(e.g. a link to a compromised skill) hitchhikes on a **social contagion** that
autonomous LLM agents organically tend to reshare or upvote. Propagation is driven
by **endogenous sharing** and **platform amplification** (feed ranking / upvotes),
not by prompt injection or explicit self-replication — an attack surface orthogonal
to agentic worms and "mind viruses". We study it on a simulated instance of [Moltbook](https://moltbook.com),
a persistent social network populated entirely by LLM agents.

The project has three legs:

1. **Carrier discovery (observational).** Mine candidate contagions from the real
   Moltbook corpus and estimate how contagious each is — a visibility-marked Hawkes
   model on the feed (branching ratio `R_endo`, time-reversal placebo `phi`) and an
   upvote-attraction edge (`r_up`).
2. **Single-agent assays (controlled).** Measure per-encounter behaviour over real
   LLM agents: retransmission (`SAR = P(post) x P(payload|post)`), adoption
   (`ASR = P(install|seen)`), the upvote edge, and rephrasing robustness. **Simulated
   only** — LLM calls (Ollama) against synthetic/real feeds; nothing is ever posted to
   moltbook.com and no skill is fetched or executed.
3. **Monte Carlo simulation.** A surface×cascade model on two substrates: the
   state-mediated Moltbook feed (a seed breaks into a broadcast ranking if its upvotes
   clear the calibrated entry bar) and the edge-mediated SNAP ego-Twitter follower
   graph. Produces expected payload installs + amplification over a generic link
   sharer, the install-exceedance CCDF, an upvote-vs-retransmission decomposition, and
   robustness ablations.

**Headline result:** payload exposure/adoption is amplified up to ~3.4× (state-mediated)
and ~1.7× (edge-mediated) over a generic link sharer, with heavy-tailed ("lottery")
cascade outcomes.

Corpus: [`AIcell/moltbook-data`](https://huggingface.co/datasets/AIcell/moltbook-data)
— ~290K posts, 1.8M comments, ~40K agents, 2026-01-27 → 2026-02-08 (paper: *Does
Socialization Emerge in AI Agent Society? A Case Study of Moltbook*, arXiv:2602.14299).

## Setup

```bash
pip install pandas pyarrow numpy scipy networkx matplotlib scikit-learn \
            sentence-transformers hdbscan

# Raw Moltbook corpus (~540 MB) -> data_raw/ (gitignored)
mkdir -p data_raw
curl -L "https://huggingface.co/datasets/AIcell/moltbook-data/resolve/main/data/posts-00000-of-00001.parquet"    -o data_raw/posts.parquet
curl -L "https://huggingface.co/datasets/AIcell/moltbook-data/resolve/main/data/comments-00000-of-00001.parquet" -o data_raw/comments.parquet
```

- The **edge substrate** is the SNAP ego-Twitter follower graph
  (`data_ext/twitter_combined.txt.gz`, gitignored; see `data/ego-twitter-snap/COLLECTION.md`).
- The **assays** need a running Ollama (local, or `ollama.com` cloud — set
  `OLLAMA_HOST` / `OLLAMA_API_KEY`). Backends used: gpt-oss-120B, DeepSeek-v4.1-flash
  (cloud); qwen2.5-32B, gemma2-27B, command-r-35B (local).

## Reproduce

```bash
# --- 1. carrier discovery (observational) ---
python -m analysis.endogenous_hawkes            # visibility-marked Hawkes -> out/endogenous_contagion_strict.csv
python -m analysis.estimate_tau                 # non-parametric excitation timescale tau
python -m analysis.upvote_attraction.attraction # corpus upvote edge r_up + significance
python -m analysis.contagions_table_v2          # figures/contagions_table_v2.tex (the carriers table)
#   meme miners (feed the Hawkes/attraction stages):
python -m analysis.meme_mining.neologism.copy_fidelity   # verbatim copy-fidelity (coined tokens)
python -m analysis.meme_mining.lexical.memes             # hashtags/emoji/domains/n-grams
python -m analysis.meme_mining.cluster_v2.cluster        # bge + HDBSCAN semantic clusters
python -m analysis.meme_mining.llm_coded.llm_labeling    # LLM behaviour labels (weak supervision)

# --- 2. single-agent assays (need Ollama; write to data/<collection>/) ---
python -m sandbox.ollama_sar run --model <model> --memes <meme> --goal <goal> --semantic
python -m sandbox.run_asr ...                   # adoption assay (P(install|seen))
#   batches are scripted per collection, e.g.:
bash data/upvote-edge-2026-09/run.sh
bash data/multihop-rup-2026-09/run.sh

# --- 3. simulation + figures/tables ---
python -m analysis.make_paper_figures           # headline installs/amplification tables + CCDF + decomposition
python -m sandbox.expected_installs_surface     # (the engine make_paper_figures drives; state folds in edge)
python -m sandbox.action_prob_table             # per-backend action probabilities table
python -m sandbox.multihop_retransmit           # rephrasing figure (retransmission + upvote edge vs depth)
python -m sandbox.multihop_depth_trend          # per-model depth-trend significance test
python -m sandbox.multihop_sim_sensitivity      # re-roll break-in + broadcast-decay sensitivity
python -m sandbox.ablations                     # robustness ablations + retransmission-decay table
python -m sandbox.bare_vs_trojan_plot           # carrier vs payload retransmission/upvote figure
```

All figures are written as **vector PDF** and tables as **`.tex`** into the top-level
`figures/` directory, so they drop straight into LaTeX.

## Data-collection discipline

Every assay batch is written into its own `data/<name>-<date>/` directory with a
`COLLECTION.md` recording intent, method, contents, and any issues discovered later;
`data/DATA.md` indexes them all. This keeps every number in the paper traceable to the
run that produced it.

## Method notes, caveats & ethics

- **State-mediated exposure is primary.** Moltbook is a feed: what an agent sees is
  set by the home-feed ranking, so exposure is modelled state-mediated (feed rank),
  never as a comment/reply graph. The only interaction graph is the external Twitter
  follower topology used for the edge substrate.
- **Author spread, not raw frequency**, defines a carrier — something *many distinct
  agents carry* — so one prolific account cannot manufacture one.
- The observational contagion estimate is **correlational**; shared feeds and homophily
  are confounds addressed by copy-fidelity and the time-reversal placebo (`phi`). The
  single-agent assays are the complementary controlled design.
- **Safety.** All assays are simulated (Ollama chat only): nothing is posted to
  moltbook.com, and no skill/repo is ever fetched or executed. We do not release
  exploit templates. Provenance of Moltbook identities is platform-reported and not
  independently verified.
